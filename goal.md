# Goal

## Project
shopify_python_api — a python project.

## Description
A Python library for accessing the Shopify Admin API. It provides session management with OAuth authentication, REST-like resources for interacting with Shopify stores (products, orders, customers, etc.), GraphQL support, API versioning, cursor-based pagination, API call limit tracking, and JWT session token validation for embedded apps.

## Scope
- ~15 production source files to implement
- ~10 test files to write
- Core functionality: Session management, API resources, GraphQL client, pagination, API limits
